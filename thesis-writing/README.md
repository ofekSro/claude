# כתיבת התזה עם Claude Code

הכלים בתיקייה הזאת משמשים לכתיבת התזה ב-LaTeX, תת-פרק אחר תת-פרק.
הם קוראים את ה-`CLAUDE.md` של תיקיית התזה ומצייתים לכללים שלו: אנגלית בריטית, בלי נקודה-פסיק, גוף שלישי, ציטוטים רק ממפתחות שקיימים ב-`bibliography.bib`, ולא משנים טקסט שלא ביקשתי.

## מה יש כאן

| כלי | סוג | תפקיד | משנה קבצים? |
|---|---|---|---|
| `/section` | skill | כתיבת תת-פרק: תוכנית, פסקאות, בדיקת רצף, התאמה לפרק | רק פסקאות שביקשתי |
| `/cite-check` | skill | בדיקה שהמאמרים המצוטטים באמת אומרים מה שכתבתי, עם עמוד וציטוט | לא |
| `section-planner` | סוכן | הופך מפת דרכים מהצ'אט לקובץ תוכנית | רק `plans/` |
| `paragraph-writer` | סוכן | כותב או משכתב פסקה אחת לפי התוכנית | רק הפסקה שביקשתי |
| `flow-reviewer` | סוכן | עיניים טריות: רצף בתוך תת-הפרק, והתאמה לפרק ולתזה | לא |
| `citation-verifier` | סוכן | למאמר אחד: איפה כל טענה מופיעה והאם היא נתמכת | לא |

הסוכנים שדורשים שיפוט רצים על Fable 5. אם Fable 5 לא זמין או מסרב, הם עוברים ל-Opus 5.5 ומודיעים על כך.

## התקנה

מהשורש של הריפו:

```powershell
.\install.ps1
```

הסקריפט מעתיק גם את התיקייה הזאת ל-`~/.claude`, כך שהכלים זמינים בכל פרויקט.

## מחזור העבודה על תת-פרק

### 1. מפת דרכים בצ'אט

פותחים את תיקיית התזה ב-Claude Code ומדברים על תת-הפרק כמו תמיד: מה הוא צריך להכיל, באיזה סדר, מה לא להכניס.
כשמגיעים להסכמה:

```
/section plan ssec:PrS_Method
```

נכתב `plans/ssec_PrS_Method.md`. לכל פסקה: טענה אחת, ראיה (איור, משוואה, נתון), מקורות מה-bib או NEEDCITATION, ומעבר לפסקה הבאה.
קוראים, ומתקנים בצ'אט אם צריך. מרגע זה התוכנית לא הולכת לאיבוד גם אם השיחה מתארכת.

### 2. כתיבה, פסקה אחר פסקה

```
/section write ssec:PrS_Method 1
/section write ssec:PrS_Method 1 "קצר יותר, פתח עם הפער בספרות"
/section write ssec:PrS_Method all
```

- כל פסקה נכתבת תחת שורת הערה `% [P1] כותרת` בקובץ ה-tex. זה לא מופיע ב-PDF, ומאפשר לבקש "כתוב מחדש את 3" בלי לנחש איפה היא.
- **לא למחוק את העוגנים.** הסוקר והכותב משתמשים בהם.
- הערה בגרשיים משכתבת את הפסקה לפי ההערה, ורק אותה.
- `all` כותב את כל הפסקאות ברצף, כל אחת רואה את הקודמות.

### 3. בדיקת רצף בתוך תת-הפרק

```
/section review ssec:PrS_Method
```

סוכן שלא כתב את הטקסט בודק: טענה אחת לפסקה, מעברים, חזרות, סתירות, סימנים שלא תואמים ל-List of Symbols, מונחים שמשנים שם באמצע.
מקבלים רשימת ממצאים ממוספרת עם מספרי שורות. שום דבר לא משתנה.

```
/section apply ssec:PrS_Method 2 5
```

מיישם רק את הממצאים שבחרתי. שינוי סדר פסקאות או נגיעה מחוץ לתת-הפרק מוצגים קודם לאישור.

### 4. בדיקת המקורות

```
/cite-check ssec:PrS_Method
```

לכל משפט עם `\cite`: עמוד במאמר, ציטוט מילולי, ופסק.

| פסק | משמעות |
|---|---|
| נתמך | המאמר אומר את זה, באותו היקף ובאותה עוצמה |
| נתמך חלקית | המאמר אומר את זה בתנאים, בטווח צר יותר, או על גודל אחר. מגיע ניסוח מתוקן |
| לא נמצא | נקרא והטענה לא שם |
| המקור טוען אחרת | יש ציטוט שסותר |
| מקור משני | המאמר רק מצטט מישהו אחר. כדאי לשקול לצטט את המקור |

"נתמך חלקית" הוא הממצא החשוב. למשל המאמר אומר "עבור התצורות שנבדקו" והמשפט שלי כללי, או שהמאמר מדבר על לחץ מוחזר והמשפט על לחץ צד.

### 5. התאמה לפרק ולתזה

```
/section fit ssec:PrS_Method
```

בודק מול פסקת מפת הדרכים בפתיחת הפרק, מול תת-הפרקים לפני ואחרי, הפניות `\ref` פנימה והחוצה, ועקביות מספרים עם שאר התזה.

## שתי דרכי עבודה

- **מלאה**, לתת-פרק חדש: `plan`, `write`, `review`, `cite-check`, `fit`.
- **מינימלית**: כותבים בצ'אט כמו תמיד, ובסוף מריצים רק `review`, `cite-check` ו-`fit`. זה כבר נותן את הרווח העיקרי: בודק שלא כתב את הטקסט.

## בדיקת מקורות בלי קשר לתת-פרק

```
/cite-check Content/7.LiteratureSurvey.tex:142
/cite-check Content/7.LiteratureSurvey.tex:120-160
/cite-check key fouchier2017experimental
```

- שורה אחת: כשכתבתי משפט ולא בטוח שהמאמר באמת אומר את זה.
- טווח: כמה פסקאות.
- `key`: כל מקום בתזה שמצטט מאמר אחד. שימושי אחרי שקראתי מאמר מחדש.

ההתאמה בין מפתח bib ל-PDF היא לפי שם המחבר הראשון והשנה בשם הקובץ בתיקיית `Papers/`.
מאמר שאין לו PDF מסומן "אין קובץ". הבדיקה לא נעשית מהזיכרון.

## ספרים ארוכים: `/ref`

ספר כמו Krauthammer או Kinney & Graham איטי לחילוץ בכל בדיקה. רושמים אותו פעם אחת:

```
/ref add "Papers/Krauthammer_2008_Modern_Protective_Structures.pdf" "Krauthammer 2008: protective structures, blast loads, SDOF, RC design"
```

נוצר קובץ טקסט עם מספרי עמודים ב-`docs/references/`, ו-`/cite-check` משתמש בו במקום לחלץ מחדש.
מאמרים רגילים לא צריכים `/ref`.

## קשר לכלי המחקר ב-compare_v7

לפני כתיבת פרקי השיטה והתוצאות:

```
/decide status
/verify trace "<נתיב לקובץ ה-tex של הפרק>"
```

הראשון, בתוך compare_v7, מראה אילו מספרים הוחלפו ואסור לצטט.
השני ממפה כל מספר בפרק לקוד ולטבלה שממנה הוא בא.

## כללים

- הכלים לא מקמפלים. PDF רק כשמבקשים במפורש.
- לא נוגעים ב-`bibliography.bib` ולא מסירים סמני `NEEDCITATION!`.
- טקסט התזה נכתב באנגלית גם כשהשיחה בעברית. ההערות שלי עוברות לכותב כפי שכתבתי אותן.
- שינוי שנוגע ביותר מפסקה אחת מוצג קודם.

## עוד לא נבנה

- `/thesis-check`: בדיקה מכנית של כללי האיות והפיסוק בכל התזה, ובניית ה-PDF עם קריאת הלוג.
- paper-sync: השוואת מאמר ISIEMS ב-Word לתזה.
