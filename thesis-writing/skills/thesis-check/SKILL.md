You check the owner's thesis against the rules in the thesis `CLAUDE.md`. Reply in Hebrew. Never edit `.tex` or `.bib` files. Compile only for `/thesis-check build`, which is the owner's explicit request.

The skill is designed to be economical: the script does everything a script can, agents run only when asked, and agents receive short prepared inputs instead of searching on their own.

## Stage 0: locate

1. The thesis root is the nearest directory upward with a `CLAUDE.md` and a `Content/` folder. If none, ask for the path.
2. The scripts `lint.py` and `extract_papers.py` sit next to this SKILL.md. Look first at `.claude/skills/thesis-check/` under the thesis root, then at `~/.claude/skills/thesis-check/`.
3. The chapters are those the main `.tex` loads with `\input`. Drafts are never checked.
4. Cache folder: `<thesis root>/.claude/cache/`. It holds `register_card.md` and `papers/`. These files are derived, regenerated by the scripts, and never edited by hand.

## Targets

- none or `all`: every chapter.
- a chapter number (`9`) or file name (`9.ParametricStudy.tex`).
- a section label (`ssec:PrS_Method`): the lint runs on its chapter and its findings are filtered to the section's line range; the deep review covers that section only. This is the normal way to check what was just written.

## `/thesis-check [target]` (lint only, default)

1. Run `python <lint.py> <root> [chapter file] --json`.
2. Report in Hebrew:
   - **Register table**: the reference section and its profile, then one row per chapter in the target with its profile and flagged drift. One line explaining the columns. "Too short to compare" rows without judgement.
   - **שגיאות** (severity `error`).
   - **הפרות כללים** (severity `rule`), grouped by rule. A rule with more than ten hits shows the count and the first ten.
   - **לבדיקה** (severity `check`): long sentences, paragraph lengths, intensifiers. Count and the first five of each.
   - **NEEDCITATION**: count, with a pointer to `needcite`.
3. End with: "לבדיקת בהירות ומשלב: `/thesis-check <target> deep`".

## `/thesis-check <target> deep`

1. Run the lint as above.
2. Register card: if `.claude/cache/register_card.md` is missing, or the reference section's chapter file is newer than the card, run `python <lint.py> <root> --card`.
3. Launch **thesis-style-reviewer** once per chapter in the target (or once for a section label), in parallel when there are several, front matter excluded. Give each, and nothing more:
   - the chapter path, and the section label if the target is a section;
   - the path of the register card;
   - this chapter's lint findings, as a compact list (rule, line, the matched words), so it does not repeat them;
   - this chapter's register profile row and the reference profile;
   - the `definitions` entries from the lint JSON that matter to this chapter: those whose first appearance is in this chapter or later, plus every symbol and acronym this chapter uses.
4. Report the lint part as in the default, then **משלב ובהירות** from the reviewer in full, register findings first.
5. Do not fix anything. A paragraph is rewritten through `/section write <label> N "<feedback>"`.

For a whole-thesis deep run, say before launching how many reviewers will run, since each reads a full chapter.

## `/thesis-check lint [target]`

Same as the default, printed from the script's readable output (without `--json`).

## `/thesis-check needcite [target]`

1. Run `python <extract_papers.py> <root>`. It extracts only new or changed PDFs.
2. Run the lint with `--json` and collect `needcitation` and `cite-key-not-in-bib` in the target, each with its full sentence.
3. Launch **citation-finder** with the list, the cache folder `.claude/cache/papers/`, and the bibliography path. Split into parallel batches only above about ten markers.
4. Report the candidates as returned. A source with no bib entry must be added to `bibliography.bib` by the owner before it is cited. Do not insert any citation.

## `/thesis-check build`

Launch **latex-builder** for the thesis root. Report its findings, and for each undefined reference or duplicate label give the lint location too.

## Rules

- Read-only on the thesis and its bibliography. The only files written are the derived cache files above.
- No compilation outside `build`.
- Hebrew in replies, English for any proposed thesis text, in the thesis style.

## Model fallback

thesis-style-reviewer runs on Opus 5.5 (`model: claude-opus-5-5`). If it fails because Opus 5.5 is unavailable or out of usage, relaunch it once with the Agent tool's `model: "claude-fable-5"` override. citation-finder runs on Fable 5; if it refuses on safety grounds or Fable 5 is unavailable, relaunch it once with `model: "claude-opus-5-5"`. Say in the reply when a fallback was used. Do not rephrase a task to get around a refusal; if the fallback also declines, report it to the owner.
